# Statistics

Mean:

$$\bar{x} = \frac{\displaystyle \sum_{i = 1}^{n} f_i x_i}{\displaystyle \sum_{i = 1}^{n} f_i}$$

Mode:

$$\text{Mode} = l + \frac{f_1 - f_0}{2f_1 - f_0 - f_2}h$$

Median:

$$\text{Median} = l + \frac{\frac{n}{2} - cf}{f}h$$
